# Visual languages — the agent's internal map

A condensed map of the visual languages software can speak, organized by
family. **This file is agent-internal vocabulary. Never present these names
to the user as a menu.** Named styles invite cargo-cult picks and produce
the same handful of AI-flavored pitches every run. Instead:

1. Learn what the user wants in plain language (the interview in SKILL.md).
2. Use this map to locate the *principles* those answers point at — density,
   temperature, texture, depth, ornament, era, attitude.
3. **Blend.** A real direction mixes principles from several languages and
   leaves others out. Combine at the principle level (Bauhaus geometry +
   cassette-futurism warmth + editorial hierarchy), never as sticker
   blending (a Bauhaus logo on a Frutiger Aero background).
4. Explain the resulting direction to the user in simple prose — what it
   does, why it fits their answers — without naming the sources unless
   they ask.

## The dimensions of visual language

Every visual direction is a position on these axes. Interview and blend
along them; they are how you explain options without jargon:

- **Energy** — calm and quiet ↔ loud and electric.
- **Density** — spacious, one idea per screen ↔ information-dense,
  terminal-like.
- **Warmth** — cool/neutral (greys, blues) ↔ warm (paper, amber, clay).
- **Texture** — flat and clean ↔ tactile (grain, glass, chrome, wood).
- **Depth** — single flat plane ↔ layered (shadows, translucency, blur).
- **Ornament** — bare, type-only ↔ decorated (borders, motifs, illustration).
- **Seriousness** — solemn, trustworthy ↔ playful, opinionated.
- **Era** — contemporary ↔ period (70s consoles, 90s web, Y2K, mid-century).
- **Grid discipline** — strict alignment and columns ↔ loose, organic,
  diagonal, or collaged.
- **Motion attitude** — still ↔ snappy/productive ↔ expressive/physical.

## The family map

Twelve territories, each with its center of gravity. Starter values are
starting points, not recipes — refine to the product.

- **Minimalist / monastic.** Restraint as identity. System fonts, one
  accent, spacing carries hierarchy; or warm emptiness (unbleached paper
  `#F4F0E6`, off-black ink, never pure #000/#fff) that invites the user to
  complete the page. Best for writing tools, utilities, contemplative
  products.
- **Editorial / publication.** Content as hero. Serif display + generous
  hierarchy, or strict Swiss grids with one accent (often red). Best for
  reading products, docs, journalism, marketing pages.
- **Historical movements.** Bauhaus (primary shapes mapped to primary hues,
  shape-as-affordance), Constructivism (diagonal axes, photomontage,
  red/black/cream), Memphis (squiggles, terrazzo, pastel+black). Strong
  grammar; use sparingly — full immersion tires fast.
- **Retro futurisms.** Cassette futurism (amber CRT, beige plastic, wood —
  70s space-hardware optimism), Frutiger Aero (aqua, glass, bubbles —
  mid-2000s hopeful tech), Y2K chrome (liquid metal, lime+orange — anxious
  pre-millennium), Atompunk (mid-century atomic-age). Nostalgia with a
  thesis about technology.
- **Internet-native.** Vaporwave (pink/teal grids, elegy), hauntology
  (lost futures, paperback + library-music), liminal spaces (fluorescent
  emptiness). Irony-adjacent; works for products that know their audience.
- **Maximalist / decorative.** Ornament-forward: borders, motifs, pattern,
  illustration at scale. Risky for tools, powerful for brands.
- **Constraint / craft.** Deliberate limits as beauty: one typeface, two
  colors, ASCII, print-like discipline. Roguelike/ASCII and brutal-minimal
  live here too.
- **Cultural / regional grammars.** Barragán (saturated plaster planes),
  Marimekko (one enormous motif), girih geometry (aperiodic tile systems),
  Chromolitho print density, East-Asian information density. See the
  guardrail below before drawing on these.
- **Refusal / anti-design.** True brutalist web (system Times, default blue
  links), one-button products. Identity through what the product refuses.
- **Atmosphere / depth.** Cyberpunk neon (dark + electric glow), aurora
  gradients (painterly light), spatial glass (translucency, refraction,
  depth-stacking). Mood as the product.
- **Function / density.** Trading-terminal density (mono everywhere,
  green/red on deep navy), soulslike restraint (affordances removed, not
  styled away). For power users who live in the tool.
- **Premium / luxe.** Restraint + expensive materials: hairline rules,
  wide tracking, dark + metallic, generous negative space.

## Signature moves worth stealing

- **One enormous motif** (Marimekko): a single oversized graphic element
  does all the branding; everything else goes quiet.
- **Walls of color** (Barragán): a full-bleed saturated plane as the
  surface a form floats on.
- **The diagonal** (Constructivism): one strong diagonal axis energizes an
  otherwise quiet page.
- **Chrome as world-building** (cassette futurism): bezels, screws, and
  labels make a UI feel like an object.
- **The hold-beat** (tea ceremony / film): a deliberate pause or
  preparation step makes the main action feel earned.
- **Borrowed scenery** (Japanese gardens): let the OS, the content, or the
  terminal do the decorating; frame it, don't compete with it.

## Cultural borrowing guardrail

When a direction draws on culturally-anchored grammar (Barragán, Marimekko,
girih, Chromolitho, East-Asian density, Adinkra/Kente, and similar):

- **Borrow the principle, not the iconography.** Generative-tile geometry
  is borrowable; specific sacred patterns from specific sites are not.
- **Don't flatten cultures into one style.** "Indian Chromolitho" carries
  centuries of religious, regional, and class meaning.
- **Cultural authority changes the rules.** A project built by/for/with
  the community may use specific iconography appropriately.

Surface a one-line note to the user when a blend leans on these — not as a
warning, as craft honesty.
