# .research/ Conventions

owner: workbench

Working contract for the research substrate: externally sourced evidence and
grounded synthesis that informs work, never the reverse. Aligned with
`.work/CONVENTIONS.md` and `AGENTS.md`.

## Layout

```
.research/
  CONVENTIONS.md
  attestations/<handle>.md   # per-source first-read; the citation anchor
  briefs/<id>.md             # cross-source synthesis
  bibliography.yaml          # GENERATED by build-knowledge-index.py — never hand-edit
```

## The grounding floor

- Fetch every grounding source during the current engagement. Model memory may
  guide a search but may never become a citation, URL, date, DOI, or other
  bibliographic fact.
- Attest before synthesis: before citing a detail, write
  `.research/attestations/<handle>.md` with `source_handle`, `fetched`,
  `source_title`, `source_url` frontmatter, a source-faithful summary, and the
  numbered citable details under `## Attested details`. Attestations ground
  external http(s) sources only — never local paths, never credentialed URLs.
  Keep project framing and recommendations out of attestations.
- An unmarked cited statement must be directly supported by its attestation.
  Label cross-source or beyond-source composition as inference.

## Citation syntax

`[handle]{N}` — `handle` is the attestation's `source_handle` (lowercase
kebab-case, equal to its filename); `N` is the numbered detail under that
attestation's `## Attested details`. Put the detail in the attestation *before*
citing it in a brief.

## Briefs

`.research/briefs/<id>.md` carry `id`, `kind: research-brief`, `summary`,
`updated`, and a non-empty `source_handles` list. Every brief contains
`## Disconfirming evidence` — record meaningful counterevidence, or state the
bounded search that found none. When sources diverge, state positions side by
side; never average contradictions away. Optional frontmatter `relationships`
(`supports`, `contradicts`, `informs`, `supersedes`) targets are repo-relative
paths.

## Privacy and sensitive data

Never fetch, attest, synthesize, or index PII, PHI, credentials, session
material, or private patient/member data through an LLM-connected surface.
Stop and request redaction, narrowing, or an approved non-LLM workflow.

## Validation

```bash
python3 <workbench-plugin-root>/scripts/lint-research.py .
python3 <workbench-plugin-root>/scripts/build-knowledge-index.py .
python3 <workbench-plugin-root>/scripts/build-knowledge-index.py . --check
```

`.knowledge/index.json` and `.research/bibliography.yaml` are generated
artifacts — committed, deterministic, rebuilt by the commands above, never
hand-edited. A failing lint is a real defect: fix the work, never game the
check.
