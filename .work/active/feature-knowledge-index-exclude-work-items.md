# Keep work items out of the knowledge index

The Workbench knowledge index never lists active, backlog, or completed work
items. A normal builder run removes any previously indexed items, while changes
to those items alone do not stale the index. Keep conventions, release summaries,
and design attachments discoverable. Verify the builder behavior, refresh this
repository's index, and align the published Workbench contract.
